# Hosting

Where things run. Cost target: **$0**.

- **[[GitHub-Pages]]** — free static hosting. Already serves [[focus-timer]].
- **[[Railway]]** — Node host referenced by [[E-Companion]] and [[github-dashboard]] configs.
- **Render (free)** — chosen host for **BrainOS** (the real Node app: custom server + WebSocket + chokidar). Persistent process, custom domain, free SSL.
- **[[Cloudflare]]** — DNS for [[Domains|postiusgroup.com]] (not the app host: it can't run the Node server).

See [[Deployment]] for the BrainOS pipeline. Back to [[BRAIN-INDEX]].
